# Week 1 — Wazuh Deployment and Initial Event Validation

## Objective

Deploy Wazuh with Docker, connect Linux and Windows endpoints, and inspect security events generated by controlled test activity.

## Work completed

- Generated certificates for the deployment.

## Suggested validation checklist

For each event, record and verify:

- [ ] Test endpoint and hostname
- [ ] Test date/time and time zone
- [ ] Expected event and observed event
- [ ] Wazuh rule ID and rule description
- [ ] Source fields (for example, username, source IP, process name) where applicable
- [ ] Whether the event was an alert or a raw/archived event
- [ ] Screenshot with sensitive values removed

## Issues and follow-up

- Add sanitized Compose and agent configuration examples.
- Record exact installation commands and software versions.
- Add rule IDs and event details only after checking them in the dashboard.
- Re-run each test to confirm that the result is repeatable.
